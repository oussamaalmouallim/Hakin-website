# Prompt — Sélection de plusieurs pièces (carrousel)

**Taille** : 1080 × 1350, première image du carrousel.
**À joindre** : `marketing/images/Gemini_Generated_Image_dg33pldg33pldg33.jpeg` (image de style).
**À générer une seule fois** : c'est un modèle.

## Prompt à copier

Remplacez `[NOMBRE]` par 3 ou 4.

```
Vertical 1080×1350 collage template in the style of the attached reference image. [NOMBRE] empty tilted photo frames of different sizes overlapping like a scrapbook, each filled with a plain light grey (#E6E6E6) placeholder, with thin offset borders in sand beige (#D4BB96) and cream (#F5EFDF). A wide sand beige dry-brush stroke across the top, empty, for a title. Deep charcoal black background (#111111) with a faint street-map line texture (#050505). Cream brush strokes behind the frames, slanted about 10 degrees. Small mustard yellow (#E6B12A) halftone dot grids in two opposite corners. No people, no clothing, no brand logos, no letters, no watermark.
```

## Après la génération (Canva)

1. Une **vraie photo** par cadre.
2. Sur le pinceau du haut : le titre en Archivo Black noir (« SÉLECTION SWEATS »).
3. Images suivantes du carrousel : une pièce par image avec le modèle [`03-produit-seul.md`](03-produit-seul.md).
4. Dernière image : sur le noir, « Commandez sur le site ou sur WhatsApp » + adresse du site.

## Vérifier avant de publier

- [ ] Toutes les pièces sont en vente sur le site.
- [ ] Six cadres au plus (au-delà, illisible sur téléphone).
