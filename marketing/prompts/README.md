## Toujours joindre

1. **L'image de référence** : `marketing/images/Gemini_Generated_Image_dg33pldg33pldg33.jpeg` (la couverture). C'est
   elle qui garde tous les visuels cohérents.
2. Pour le logo : `web/medias/marque/logo-profil-1080.png`.

## Les trois règles qui ne changent jamais

- **L'IA fait le décor, la boutique fournit le produit.** Une pièce à vendre = sa vraie photo, posée dans le cadre
  vide dans Canva.
- **Aucun texte écrit par l'IA** : titres, prix et mentions se posent dans Canva.
- **Aucun logo de marque ni « H » dessiné par l'IA** : le « H » vient de `web/medias/marque/logo-monogramme-2000.png`,
  teinté sable `#D4BB96`.

## Textes dans Canva (pour tous les modèles)

| Élément | Police | Couleur |
|---|---|---|
| Titre, nom de pièce, prix | Archivo Black, capitales | crème `#F5EFDF` sur le noir, noir `#111111` sur le sable |
| Texte courant | Space Grotesk | idem |
| Étiquette (« NIKE », « NOUVEAU ») | JetBrains Mono, capitales espacées | idem |
| Mention fixe en bas | Space Grotesk : « Paiement à la livraison · Casablanca » | crème |

Un prix n'apparaît que s'il est **saisi dans l'admin** ; sinon « Prix sur WhatsApp ».
